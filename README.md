## Credits

PixelConquest is a Roblox adaptation of [OpenFront](https://github.com/openfrontio/OpenFrontIO), the open-source territory-conquest strategy game. The original game design and concepts belong to OpenFront and its contributors. This version was rebuilt for Roblox and modified by 8Yoonie, with changes to the system architecture, units, maps, matchmaking and in-game products. Basic game mechanics have also been simplified for Roblox audiences. See the original repository for its source and license.
