## Credits

PixelConquest is a Roblox adaptation of [OpenFront](https://github.com/openfrontio/OpenFrontIO), the open-source territory-conquest strategy game. The original game design and concepts belong to OpenFront and its contributors, and parts of the core game logic were originally ported from OpenFront's source. Since then, the game has been largely rebuilt for Roblox by 8Yoonie, with changes to the system architecture, units, maps, matchmaking and in-game products. Basic game mechanics have also been simplified for Roblox audiences. See the original repository for its source and license.
